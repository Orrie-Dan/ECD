Updated ECD Mapping Tool for Facilities for Digitization

This updated ECD mapping tool is built on the previous one with additional data/information from the current the National ECD Standards (2024). The previous tool gives the status of ECD facility in all settings. The current/updated follow the current ECD standards which group ECD facilities into 4 types depending on settings. The tool has general information which will be the same for all settings, then separate standards for each setting.

Ranking of the ECD facility for compliance with the standards: 

Note: 
The scoring was done by considering the weight of a standard item
Some standard items had more than one indicators, every indicator counted
Initially every standard item has 1 score by default if it exists
Once the standard exists, then follows checking what it entails which gives its weight. 
Each standard section (e.g. Nutrition) has a sub-total of scores.
There is a grand total summing up all the sections and ging the total scores for the setting.
The total score is rounded to a hundred (%).
The percentage gives the rank of the ECD setting in compliance with the ECD Standards
The ranks are attributed as follows: 
GREEN: 90%-100%
BLUE   : 70%-89%
YELLOW: 50%-69%
RED   :       Below 50%
